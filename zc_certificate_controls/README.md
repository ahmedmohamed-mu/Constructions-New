# Ziij Construction - Certificate Controls

- **WIR (work inspection request)**: site measurements enter a certificate only after the consultant approves them (setting "Inspection before certification").
- **Consultant review**: quantities submitted vs certified per BOQ item; every cut becomes a quantity claim, carried to the next certificate.
- **Deductions**: owner (withholding tax, social insurance, penalties, utilities) and subcontractor (materials issued, back-charges, penalties, withholding tax); withholdings are settled against the receivable / payable.
- **Subcontractor approval chain**: site engineer -> technical office (QS) -> project manager -> accounts; back-to-back check against the owner certified quantity of the same BOQ items.
